DSNap

Configuration sur votre ordinateur. Rien de ce que vous saisissez ici n'est envoyé à Claude.

Remplissez les étapes dans l'ordre. Le mot de passe net-entreprises est chiffré dans le trousseau de votre système ; les informations de la société et du président sont écrites dans votre dossier de paie, sur cet ordinateur.

Pas encore prêt ? Essayez DSNap avec une société fictive : les dépôts vont à un simulateur, rien n'est envoyé à net-entreprises.

1Dossier de paie

Le dossier où DSNap range la configuration, les DSN, les bulletins et les retours de net-entreprises. DSNap ne lit et n'écrit aucun autre fichier.

2Compte net-entreprises

Les identifiants avec lesquels vous vous connectez à net-entreprises.fr, pour un compte inscrit au service « DSN ». DSNap s'en sert pour déposer vos déclarations et lire les retours, rien d'autre.
